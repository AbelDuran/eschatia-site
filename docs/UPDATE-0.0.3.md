# Проверка ТЗ «Правки 0.0.3 version GPT»

Проверено 04.10.2026. Документ разделяет текущие исправления P0–P2 и будущее игровое развитие P3. Ниже — фактический статус, без объявления будущих функций готовыми.

## Выполнено в этом обновлении

- Пункты 2–4: приветственный диалог на главной, выбор новичка/опытного игрока, сохранение в браузере, повторное изменение. Опытный игрок получает сводки вместо вводного экрана, новичок — маршрут /start; архив доступен обоим. Нативный dialog поддерживает клавиатуру, Escape и удержание фокуса.
- Пункты 5–6, 17: архив с сортировкой по соответствию, названию, созданию и обновлению; фильтр типов новостей; параметры сохраняются при пагинации. Добавлены типы «Правила», «Изменения мира», «События игроков», «Патчноуты» и категории истории/прочих материалов. Поиск проверен на 600 записях, в том числе на исключение черновиков.
- Пункты 7, 11, 14: редактируемые разделы теперь доступны не только странам, но и лору, организациям, расам, новостям. Для механик есть кнопка добавления структуры «Что это / Как работает / Что может игрок / Ограничения». Пустые правила автоматически не придумываются. Существующий лор сохранён.
- Пункт 10: /start состоит из восьми этапов: проект, мир, правила, происхождение, анкета, проверка, одобрение, начало игры. Содержимое отделено от компонента в app/data/start-steps.json. Неизвестные сроки и канал первого поста не выдуманы.
- Пункты 26–27: индивидуальные title, description, canonical, Open Graph и Twitter для всех типов материалов; закрытые материалы не выдают заголовки в metadata. Оформленные 404 и экран временной ошибки. Исправлен блок похожих страниц на несуществующих статьях.
- Пункт 28: локальные фоновые изображения новостей и портретов проходят оптимизатор Next.js; статья использует адаптивный Image; гербы загружаются лениво. Повторные чтения статьи и индекса в одном серверном рендере объединены React cache, без межпользовательского постоянного кеша.
- Пункт 29: заметный focus-visible, управление диалогом с клавиатуры, aria-expanded у мобильного меню, отключение анимаций и плавной прокрутки при prefers-reduced-motion, увеличенные мобильные кнопки инструментов.

- Централизованные статьи с идентификаторами, версиями и связями; ссылки на связанные материалы используют актуальное название целевой записи.
- Discord-авторизация, один персонаж, приватные черновики, отправка и возврат на правки, обсуждение с администрацией, история и публичная страница после одобрения.
- Панель администратора: создание/редактирование/публикация материалов, заморозка персонажа, удаление и восстановление, выдача ролей владельцем.
- Общая музыка, управление звуком, светлая/тёмная тема, кнопки возврата, раскрытие каталогов до полного списка и сворачивание до четырёх.

## Будущие функции P3 — не реализованы в этом релизе

Документ прямо помечает эти функции как будущие: мироквесты, достижения, состояние мира, интерактивная хронология, карта, сюжетные линии, граф связей. Для них нельзя подставлять выдуманные сюжетные данные или автоматически раскрывать тайны.

Архитектурное направление: отдельные сущности событий/сюжетных линий со стабильными ID и ссылками на articles.id; изменения состояния мира — версионируемые записи, а не текст в компонентах. Для ограниченного контента необходимы серверные правила доступа и таблица разрешений/открытий пользователя; условия скрытых достижений не должны уходить в HTML, поиск, metadata или клиентский JavaScript. Временные события потребуют starts_at/ends_at и проверки времени на сервере. Текущие draft/deleted уже исключаются из публичного индекса, но это не система персональных открытий. Структуры таблиц будущих функций не создавались без согласованных игровых правил.

Подсказки поиска при вводе также отмечены как будущее пожелание; текущий серверный поиск с фильтрами сохранён. Автоматический пересказ каждой механики и миграция всего старого оформления организаций/рас в универсальные разделы не выполнялись: это отдельная редакционная работа, а не незаметная перезапись лора.

## Проверки и ограничения

- 23 автоматических теста прошли, включая 600 материалов, права и приватность, жизненный цикл анкеты, JSON PostgreSQL и безопасные metadata.
- Production build прошёл. Локальная сборка без DATABASE_URL; производственная БД не изменялась. Новая миграция не нужна.
- ESLint: 0 ошибок, 4 предупреждения об оставшихся img (гербы и редакторские превью).
- В браузере проверены главная, архив, длинная статья на 360/390/768/1024/1440 px: горизонтального переполнения нет. Проверены переключение и сохранение маршрута, фильтры, /start и 404. Это выборочная проверка шаблонов, не утверждение о проверке каждого материала на каждом устройстве.
- Внешние HTTPS-изображения остаются без серверной оптимизации: произвольные чужие хосты не добавлены в allowlist. Их размер зависит от источника.
- Полного замера на реальной медленной мобильной сети и проверки реального Discord-входа в этой локальной сессии не было. Статус Vercel после push нужно проверять отдельно.
